# Legacy V1 archive

The authoritative V1 snapshot is the immutable Git tag `v1.0.0-rps-yolov8`.

`rps_yolov8/` retains only the small historical scripts, legacy `data.yaml`, and dataset provenance text needed for study. Dataset images, generated runs, result copies, and model weights remain available from the V1 tag but are intentionally absent from the V2 tree.

Legacy files are not imported by the V2 package, are excluded from lint/type checks, and are not claimed to run on a clean machine.
